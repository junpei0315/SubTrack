# PRD（Product Requirements Document）

**目的**: プロダクトとして「何を・誰のために・なぜ作るか」を定義し、チームの共通認識を作る文書。

実装・UI のドメイン用語・優先度判断の参照元として扱う。詳細な機能一覧が別管理（Notion 等）の場合は本書の該当節にリンクを置く。

---

## 1. 背景・課題

### 現状

- サブスク管理ができていない。無駄な出費がある。
- 個人が契約しているサブスクリプションが複数のサービス・カードに分散しており、全体像を把握できていない。
- 月々いくら払っているか合計金額がわからない。
- 使っていないサービスに気づかず課金され続けている。
- 更新・解約のタイミングを見逃し、不要な支払いが発生している。
- 値段に見合った使用量ではない。
- メモなどに手作業で整理しなければならない。

### 課題

- サブスクの契約状況を一元管理する手段がない。
- 無駄な出費に気づけず、家計の最適化ができない。
- 無駄な出費でお金がなくなる。

### 解決したいこと（このプロダクトで何を解決するか）

- 現段階で契約しているサブスクの**総額**と**期間**が把握できる。
- **節約**を図れる。
- **何をどれくらい使用しているか**把握できる状態にする。
- **更新・解約タイミングのリマインド**。
- **使用頻度**を明確化し、各サブスクの需要を可視化する。

## 4. ターゲットユーザー（ペルソナ）

| 項目                             | 内容                                                                                                         |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **ユーザー像**                   | サブスクを多く契約しているユーザー。                                                                         |
| **抱えている課題**               | 把握不足、未使用のサブスクに払いすぎている。                                                                 |
| **このプロダクトで得られる価値** | 無駄な出費を抑えて他の用途に回せる。                                                                         |
|                                  | サブスクの全体像を可視化することで、お金の使い方を自分でコントロールできるようになり、日常の質を高められる。 |
|                                  | **把握する** — 何にお金を使っているかが一目でわかり、生活の解像度が上がる。                                  |
|                                  | **見直す** — 使っていないサービスに気づき、生活習慣を客観視できる。                                          |
|                                  | **最適化する** — 無駄を削ぎ落とし、本当に価値あるものにだけお金を使える状態になる。                          |
|                                  | **アップデートする** — お金の使い方を継続的に改善することで、日常そのものの質が上がっていく。                |
